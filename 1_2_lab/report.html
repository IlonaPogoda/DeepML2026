Что сделано

Архитектура проекта сохранена: текст служит Query, аудио — Key/Value в nn.MultiheadAttention, затем residual, masked mean pooling, общий слой и две головы (эмоция и тональность) с общей функцией потерь. Изменения касаются данных, предобработки, входа текстовой ветки и процедуры обучения.

Данные

  • Весь MELD: 9988 / 1108 / 2610 реплик вместо 1200 / 250 / 250.
  • Тест по всей выборке, а не по первым 250 клипам архива, поэтому оценка надёжнее.
  • Типографские ’ “ ” — … приводятся к ASCII: раньше company’s дробилось на части.
  • Для каждой реплики сохраняются до 3 предыдущих реплик диалога (без меток); подключаются через --context-turns.

Предобработка аудио

  • Удаление DC-смещения и нормализация громкости клипа.
  • Pre-emphasis 0.97: усиление высоких частот речи.
  • Обрезка тишины по краям (порог −35 дБ от максимума).
  • К 20 MFCC добавлены log-энергия, Δ и ΔΔ: 63 признака вместо 20.
  • 64 шага с усреднением по сегментам вместо интерполяции до 32 шагов.
  • Параллельная обработка на всех ядрах CPU при сборке.

Текстовая ветка

  • Вместо nn.Embedding с нуля — дообучаемый предобученный RoBERTa-base и проекция 768 → 256.
  • BPE-токенизатор вместо регулярки, длина до 128 токенов.
  • Q и усреднение — только по токенам текущей реплики (query_mask).
  • Старый вариант остаётся доступен: "text_encoder": "".

Модель

  • Hidden size 64 → 256, 4 головы внимания.
  • Обучаемые позиции аудиокадров: K/V больше не неупорядоченное множество.
  • LayerNorm после residual-сложения, dropout 0.1.

Обучение

  • GPU (CUDA) и смешанная точность fp16 вместо CPU.
  • AdamW с раздельным LR: 2e-5 для RoBERTa и 5e-4 для новых слоёв.
  • Warmup 10 % и линейное затухание LR, gradient clipping 1.0.
  • Проверка на dev после каждой эпохи; для теста берутся веса лучшей эпохи.
  • Новая метрика weighted-F1 (стандартная для MELD).

Инфраструктура

  • Docker: torch с CUDA, запуск docker run --gpus all, без yaml.
  • Датасет и веса RoBERTa скачиваются при сборке, запуск работает без интернета.
  • Загрузки докачиваются после обрывов сети и переключаются на зеркало MELD.
  • Подробный отчёт на localhost с графиками и сравнением.

Данные

MELD — реплики из сериала Friends с видео и аудио, размеченные по 7 эмоциям и 3 классам тональности. Текст и аудио сопоставляются по Dialogue_ID / Utterance_ID; один битый клип train пропущен.

Предобработка аудио

MP4→FFmpeg: 16 кГц, моно→DC + нормализация громкости→Pre-emphasis 0.97→STFT 25/10 мс, Hann→Обрезка тишины→40 mel → log → DCT → 20 MFCC→+ log-энергия→+ Δ, ΔΔ→Усреднение до 64 шагов→z-норма по train

Общий слой: Dropout → Linear 256→256 → ReLU → Dropout

Linear 256→7

Выводы и ограничения

  • Основной прирост дали полный объём данных и предобученный текстовый энкодер: эмбеддинги, обученные с нуля на 1200 репликах, не успевали выучить семантику эмоций, и модель почти всегда предсказывала neutral или joy.
  • Улучшенные аудиопризнаки (энергия, динамика Δ/ΔΔ, обрезка тишины) дают cross-attention более информативные K/V; вклад аудио в MELD традиционно меньше вклада текста.
  • Редкие классы (fear, disgust — около 2 % данных) остаются самыми сложными; это видно по F1 по классам и матрице ошибок.
  • Дальнейшие шаги: контекст диалога (--context-turns 2), взвешенная функция потерь для редких классов, предобученный аудиоэнкодер (wav2vec2 / HuBERT).
